# Skyla Zhao | Data Analytics & Reporting Portfolio

The interview portfolio is published through GitHub Pages. The homepage opens the standalone portfolio.

## Offline presentation

Open `public/portfolio.html` in a browser. When copying it to another computer, keep the adjacent `assets` folder with it. The portfolio does not use a network connection at runtime.

## Update the portfolio

Edit the inline configuration in `public/portfolio.html`. Keep media paths relative to that file and include only reviewed presentation copies.

Build with Node.js 22 or later using `npm install` and `npm run build`. The GitHub Actions workflow publishes the resulting `dist` directory to Pages.
